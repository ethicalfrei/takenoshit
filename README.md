# Take No Shit

A day of Punch-Out boss battles. Play at [kevinfrei.com/takenoshit](https://kevinfrei.com/takenoshit).

## Deploy

1. Import this repo in Vercel (framework: Vite / Nitro).
2. Root stays `/`. Production URL will be something like `takenoshit.vercel.app`.
3. The kevinfrei.com site iframes that URL at `/takenoshit`.
